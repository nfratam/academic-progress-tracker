Academic Progress Tracker

An Android application designed to help students organize academic terms, manage courses, track assessments, and monitor progress toward completion.

About the Application

Academic Progress Tracker provides students with a centralized way to organize their academic schedules and monitor their coursework.

  • Create, edit, and delete academic terms.
  • Manage courses and their associated assessments.
  • Search courses by name.
  • Generate academic progress reports.
  • Store academic information locally using SQLite.

  4. Follow the Android installation prompts.

Only install APK files from sources you trust. You may need to allow installation from this source in your Android settings.
